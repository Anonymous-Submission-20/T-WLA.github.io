Paper overview

Abstract

Contact-rich manipulation requires fast tactile corrections grounded in visual information and past observations. T-WLA connects visual action generation and tactile correction through shared visual memory. At each RGB update, the visual branch combines the current observation and task instruction with retrieved visual history, producing an updated visual memory and a base action chunk.

Between RGB updates, a lightweight editor combines cached visual memory, the original base action chunk, elapsed time, and fresh tactile context encoded from recent touch. It corrects only valid, unexecuted actions without rerunning vision. Future-image and future-pressure prediction provide training-only supervision; both prediction heads are removed at inference. We evaluate future hand-motion prediction on EgoTouch and Tachin, and closed-loop control on four real-world manipulation tasks.

Method

Slow vision. Fast touch.

Visual memory retains task and scene information. Tactile context captures evolving contact. The editor uses both to revise an ongoing action chunk without rerunning vision.

01

Visual memory

A memory bank stores past visual memories. Learned queries retrieve history, which the visual model combines with the current inputs. The resulting visual memory guides both action generation and tactile correction.

02

Tactile context

Recent tactile history is encoded at each touch update. Through FiLM, it modulates action features conditioned on cached visual memory, the original base chunk, and elapsed time.

03

Training-only prediction

Future-image and future-pressure prediction shape features for control. Future observations are supervision, never controller inputs. Both prediction heads are removed at inference.
